# Easy Kyrgyz · Проектная доска

Доска для заказчика: структура приложения, майнд-карта, регионы, игровой цикл, концепция, экраны драфта, стиль и журнал итераций.

- `index.html` — главная страница доски
- `map.html` — майнд-карта (масштаб щипком, тачпадом, Ctrl + колесо)
- `data.js` — все данные доски; каждую итерацию обновляется только этот файл
- `img/` — экраны из Figma (MAIN PAGE) и иллюстрации регионов
- `fonts/` — Medeo Sans (DNF Studio, SIL Open Font License 1.1)

Сайт статический, сборка не нужна. Публикуется через GitHub Pages из ветки `main`.
